## Кабинет туриста

### Структура
1. **Dashboard** - главная страница
   - Статистика заявок (карточки)
   - Последние заявки (таблица)
   - Быстрые действия (кнопки)
   - Непрочитанные сообщения

2. **Мои заявки** - список заявок
   - Фильтры по статусу
   - Поиск
   - Карточки заявок
   - Пагинация

3. **Чат с менеджером** - общение
   - Список заявок с чатами
   - Окно чата
   - Отправка сообщений
   - Прикрепление файлов

4. **Документы** - управление документами
   - Загрузка файлов
   - Просмотр документов
   - Скачивание

5. **Настройки** - профиль
   - Редактирование данных
   - Смена пароля
   - Удаление аккаунта
