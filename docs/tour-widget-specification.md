# Спецификация виджета поиска туров - Проект "Авилона"

## 🎯 Общая концепция

Минималистичный, но функциональный виджет поиска туров с интеграцией API туроператоров.
**Принцип:** Не изобретаем велосипед - используем готовые API туроператоров.

## 🔍 Фильтры виджета поиска

### Обязательные поля:
1. **Откуда** (город вылета)
   - Москва, Санкт-Петербург, Екатеринбург, Новосибирск и др.
   
2. **Куда** (страна назначения)
   - Турция, Египет, ОАЭ, Тайланд, Испания и др.
   
3. **Интервал дат вылета**
   - Диапазон дат (от - до)
   
4. **Количество ночей**
   - От 7 до 21 (с шагом)
   - Возможность указать диапазон (7-8, 7-10, 7-14)
   
5. **Количество туристов**
   - Взрослые (от 1)
   - Дети (от 0 до 17 лет) - с возможностью указать возраст каждого ребенка

### Опциональные фильтры (расширенные):
6. **Курорт**
   - Зависит от выбранной страны
   - Если курорт выбран → отели фильтруются по курорту
   
7. **Категория отеля**
   - 3★, 4★, 5★
   
8. **Питание**
   - BB (завтрак)
   - HB (полупансион)
   - FB (полный пансион)
   - AI (всё включено)
   - UAI (ультра всё включено)
   
9. **Пляжная линия отеля**
   - Любая
   - 1-я линия
   - < 100м от пляжа
   - 2-я линия
   - < 500м от пляжа
   - 3-я линия
   - < 2км от пляжа
   
10. **Рейтинг отеля**
    - Любой
    - 7+
    - 8+
    - 9+
    
11. **Выбор отеля по названию**
    - Автокомплит с поиском
    - Фильтрация по курорту (если выбран)
    - Не более 20 отелей
    
12. **Туроператор**
    - Выбор конкретных туроператоров
    - По умолчанию - все выбраны
    
13. **Диапазон цен**
    - От (мин) - До (макс)
    - В рублях (RUB)
    
14. **Дополнительные фильтры (галочки):**
    - ✓ Чартерный рейс
    - ✓ Прямой рейс (без пересадок)
    - ✓ Моментальное подтверждение

## 💼 Процесс бронирования

### Вариант A: Связь с менеджером (основной)

#### Для неавторизованных пользователей:
1. Нажимает "Связаться с менеджером" на карточке тура
2. Открывается форма заявки:
   - ФИО
   - Email
   - Телефон
   - Комментарий/пожелания (необязательно)
3. Заявка создается со статусом "new"
4. Предложение зарегистрироваться (необязательно):
   - "Зарегистрируйтесь, чтобы отслеживать статус заявки и общаться с менеджером"
5. Менеджер получает уведомление о новой заявке

#### Для авторизованных пользователей:
1. Нажимает "Связаться с менеджером"
2. Форма заявки с предзаполненными данными:
   - ФИО (из профиля)
   - Email (из профиля)
   - Телефон (из профиля)
   - Комментарий/пожелания
3. Заявка создается и привязывается к пользователю
4. Пользователь видит заявку в личном кабинете
5. Может общаться с менеджером через чат

## 🎨 Дизайн виджета

### Принципы:
- **Минималистичный** - ничего лишнего
- **Функциональный** - все необходимые фильтры
- **Красивый** - современный UI/UX
- **Удобный** - интуитивно понятный

### Структура виджета:

#### Базовая форма (всегда видна):
```
┌─────────────────────────────────────────────┐
│  [Откуда ▼] [Куда ▼] [Даты ▼] [Ночей ▼]   │
│  [Туристы ▼]  [Найти туры 🔍]              │
└─────────────────────────────────────────────┘
```

#### Расширенные фильтры (кнопка "Больше фильтров"):
```
┌─────────────────────────────────────────────┐
│  [Курорт ▼] [Звезды ⭐] [Питание ▼]        │
│  [Пляж ▼] [Рейтинг ▼] [Отель 🏨]           │
│  [Цена: от ___ до ___]                      │
│  [Туроператор ▼]                            │
│  □ Чартер  □ Прямой  □ Моментальное        │
└─────────────────────────────────────────────┘
```
