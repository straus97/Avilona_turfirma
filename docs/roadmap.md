## Цель проекта

Создать надёжный, безопасный веб-сайт и внутреннюю систему бронирования для туристического агентства «Авилона».
Три основные роли: турист, менеджер, администратор.
Система должна обеспечить полный жизненный цикл заявки, безопасный обмен документами
и управляемое взаимодействие между клиентом и менеджером.

## Принципы выполнения

- Один маленький семантический слой за раз.
- Read-only preflight перед каждым патчем.
- Чёткий список разрешённых файлов в каждом слое.
- Ручное ревью diff перед коммитом и пушем.
- PHPUnit всегда на SQLite `:memory:`.
- Никаких изобретённых дедлайнов — оцениваем по факту выполнения.

- Ролевые ссылки в email на активные переписки.

- Детерминированный порядок сообщений.
- При опросе (polling) прочитанными помечаются только непрочитанные сообщения, чей `receiver_id` равен аутентифицированному опрашивающему пользователю (`is_read` становится `true`, `read_at` — непустым); сообщения, адресованные другому участнику, остаются непрочитанными; администратор, наблюдающий за перепиской, но не являющийся ни отправителем, ни получателем, ничего не помечает прочитанным.
- Защищённое JSON-представление вложений.
- Отсутствие прямых путей к приватным вложениям в ответах API.
