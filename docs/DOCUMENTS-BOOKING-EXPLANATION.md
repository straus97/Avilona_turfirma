---

## 🎯 Как это работает?

### Структура:

1. **Личные документы туриста** (`/cabinet/documents/personal`)
   - Загружаются самим туристом
   - Хранятся в таблице `user_documents`
   - Примеры: паспорт, загранпаспорт, свидетельство о рождении детей, виза

2. **Документы по заявкам** (`/cabinet/documents/bookings`)
   - Загружаются менеджером или админом
   - Хранятся в таблице `booking_documents`
   - Связаны с конкретной заявкой (`booking_id`)
   - Примеры: договор, авиабилеты, ваучер на отель, страховка, визовое разрешение

## 🔄 Процесс работы

### Шаг 1: Турист создает заявку
- Заполняет форму с требованиями к туру
- Система создает заявку со статусом "Новая"

### Шаг 2: Назначается менеджер
- Админ назначает менеджера на заявку
- Турист и менеджер могут общаться в чате

### Шаг 3: Менеджер загружает документы
- Когда тур подобран и оплачен, менеджер загружает:
  - Договор
  - Авиабилеты
  - Ваучер на отель
  - Страховку
  - Визовые документы (если нужно)
  - Инструкции для туриста

### Шаг 4: Турист получает уведомление
- Email: "По вашей заявке #5 загружены новые документы"
- В чате: менеджер отправляет сообщение с прикрепленным документом
- На странице `/cabinet/documents/bookings` турист видит все документы

### Шаг 5: Турист скачивает документы
- Может скачать каждый документ отдельно
- Может открыть в новой вкладке (для просмотра)

## 📊 Структура БД

### Таблица `booking_documents`

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | bigint | ID документа |
| `booking_id` | bigint | ID заявки |
| `uploaded_by_user_id` | bigint | Кто загрузил (менеджер/админ) |
| `name` | string | Название документа |
| `file_path` | string | Путь к файлу в storage |
| `file_type` | string | Тип файла (pdf, docx и т.д.) |
| `file_size` | bigint | Размер в байтах |
| `created_at` | timestamp | Дата загрузки |
