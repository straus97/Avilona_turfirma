# Создание представлений для заявок (Booking Views)

## ✅ Выполнено

### Созданные представления

#### 1. `resources/views/bookings/index.blade.php` - Список заявок
**Функционал:**
- Разделение по ролям:
  - **Турист**: видит только свои заявки
  - **Менеджер**: видит назначенные ему заявки
  - **Админ**: видит все заявки в системе
- Фильтры по статусам (Все, Новые, В обработке, Подтверждены)
- Карточки с информацией:
  - Номер заявки
  - Статус (с цветовой индикацией)
  - Направление (страна, город)
  - Даты и количество ночей
  - Количество туристов
  - Клиент (для менеджера/админа)
  - Менеджер (если назначен)
  - Стоимость
  - Время создания
- Пагинация результатов
- Кнопка "Создать заявку"

**Дизайн:**
- Карточная верстка (3 колонки)
- Цветовые badge для статусов
- Иконки Bootstrap Icons
- Адаптивный дизайн

---

#### 2. `resources/views/bookings/create.blade.php` - Создание заявки
**Функционал:**
- Форма для создания новой заявки с полями:
  - Город вылета (обязательно)
  - Страна (обязательно)
  - Курорт/Город (опционально)
  - Дата вылета (обязательно, не ранее завтрашнего дня)
  - Количество ночей (обязательно, 1-30)
  - Взрослых (обязательно, 1-10)
  - Детей (опционально, 0-10)
  - Дополнительные пожелания (опционально)
- Предзаполнение данных из тура (если передан tour_id)
- Валидация на стороне клиента и сервера
- Информационные подсказки для пользователя

**Дизайн:**
- Центрированная форма в карточке
- Обязательные поля отмечены звездочкой
- Индикация ошибок валидации
- Кнопки "Отмена" и "Создать заявку"

---

#### 3. `resources/views/bookings/show.blade.php` - Детали заявки
**Функционал:**
- Полная информация о заявке:
  - Статус с цветовой индикацией
  - Направление (вылет, страна, курорт)
  - Даты и количество туристов
  - Стоимость (общая, оплачено, к оплате)
  - Пожелания клиента
  - Заметки менеджера (для менеджера/админа)
  - Информация о клиенте (для менеджера/админа)
  - Информация о менеджере (для туриста)
- Кнопки действий:
  - **Для туриста** (если статус NEW):
    - Редактировать
    - Отменить заявку
  - **Для менеджера/админа**:
    - Редактировать
    - Подтвердить (если статус PROGRESS)
    - Завершить (если статус CONFIRMED)
    - Отменить
  - **Для админа**:
    - Удалить заявку
- Боковая панель:
  - Назначение менеджера (для админа, если не назначен)
  - Статус заявки
  - Информационный блок

**Дизайн:**
- Двухколоночный layout (8/4)
- Основная информация в блоках с заголовками
- Цветовые акценты для статусов
- Иконки для визуальных подсказок

---

#### 4. `resources/views/bookings/edit.blade.php` - Редактирование заявки
**Функционал:**

- **Для менеджера/админа**:

**Дизайн:**
- Центрированная форма в карточке

### Backend (уже готов)

#### Контроллер: `app/Http/Controllers/Booking/BookingController.php`
**Реализованные методы:**
- `index()` - список заявок с учетом ролей
- `create()` - форма создания
- `store()` - сохранение заявки
- `show()` - просмотр заявки
- `edit()` - форма редактирования
- `update()` - обновление заявки
- `assignManager()` - назначение менеджера (админ)
- `confirm()` - подтверждение заявки (менеджер/админ)
- `cancel()` - отмена заявки
- `complete()` - завершение заявки (менеджер/админ)
- `destroy()` - удаление заявки (админ)

**Особенности:**
- Проверка прав доступа
- Валидация данных
- Разделение логики по ролям

#### Модель: `app/Models/Booking.php`
**Функционал:**
- Константы для статусов
- Отношения (user, tour, manager, messages)
- Scopes для фильтрации
- Accessors для форматирования
- Методы управления заявкой

#### Маршруты: `routes/web.php`
**Настроено:**
- `Route::resource('bookings', BookingController::class)` - CRUD маршруты
- Дополнительные маршруты для действий (assign-manager, confirm, cancel, complete)
- Защита middleware auth

## 🔐 Безопасность и права доступа

### Разделение по ролям:
- **Турист**:
  - Видит только свои заявки
  - Может создавать заявки
  - Может редактировать свои заявки (только если статус NEW)
  - Может отменять свои заявки
- **Менеджер**:
  - Видит назначенные ему заявки
  - Может редактировать заявки
  - Может изменять статусы
  - Может добавлять заметки
  - Может подтверждать и завершать заявки
- **Админ**:
  - Видит все заявки
  - Полный доступ ко всем действиям
  - Может назначать менеджеров
  - Может удалять заявки

### Проверки безопасности:
- Middleware `auth` для всех маршрутов
- Метод `authorizeBooking()` в контроллере
- Проверки ролей в представлениях
- CSRF защита форм
