# Backlog - Доработки и улучшения

## 🔧 Технические доработки

### ⚠️ Dropdown туристов - закрытие при удалении ребенка
**Приоритет:** Средний  
**Статус:** Отложено  
**Дата добавления:** 2026-01-08

**Проблема:**
- При удалении ребенка из списка dropdown автоматически закрывается
- Пользователю приходится заново открывать окно для дальнейших действий

**Попытки исправления:**
1. ✅ Добавлен `event.stopPropagation()` и `event.preventDefault()`
2. ✅ Добавлен `event.stopImmediatePropagation()`
3. ✅ Добавлена проверка на кнопку удаления в обработчике закрытия
4. ✅ Принудительное открытие dropdown после удаления

**Результат:** Проблема сохраняется, требуется дополнительное исследование

**Возможные решения:**
- Переписать логику обработки событий
- Использовать делегирование событий
- Изменить структуру HTML для избежания конфликтов

**Зависимости:** Нет
