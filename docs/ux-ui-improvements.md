# План улучшений UX/UI проекта "Авилона"

## Дата: 2026-01-08

## 🎨 Текущее состояние

### Используемые технологии:
- **CSS Framework**: Bootstrap 5.3.2
- **Шрифты**: Roboto (Google Fonts)
- **Иконки**: FontAwesome + Bootstrap Icons
- **JS библиотеки**: jQuery 3.7.1, Lazysizes
- **Кастомные стили**: style_min.css

### Цветовая схема:
- Основной цвет: #ffc107 (желтый/оранжевый)
- Дополнительный: #ff8c00 (оранжевый)
- Акцент: #007bff (синий Bootstrap)

## 🔍 Анализ проблем UX/UI

### 1. Главная страница

#### Проблемы:
- ⚠️ Виджет поиска туров слишком большой
- ⚠️ Кнопка "Найти туры" не выровнена
- ⚠️ Dropdown туристов работает некорректно
- ⚠️ Много вложенных стилей в самом view (плохая практика)

#### Решения:
- ✅ Вынести все стили в отдельный CSS файл
- ✅ Оптимизировать размеры полей виджета
- ✅ Исправить выравнивание кнопки
- ✅ Переработать dropdown туристов

### 2. Адаптивность

#### Проблемы:
- ⚠️ Не проверена адаптивность на мобильных
- ⚠️ Возможно переполнение контента

#### Решения:
- ✅ Добавить media queries
- ✅ Проверить на разных разрешениях
- ✅ Использовать Bootstrap responsive utilities

### 3. Производительность

#### Проблемы:
- ⚠️ Загружается много внешних ресурсов
- ⚠️ FontAwesome загружается дважды
- ⚠️ Нет минификации кастомных стилей

#### Решения:
- ✅ Убрать дублирующиеся библиотеки
- ✅ Использовать CDN с правильными integrity
- ✅ Минифицировать кастомные стили

### 4. Доступность (A11y)

#### Проблемы:
- ⚠️ Не все изображения имеют alt
- ⚠️ Нет ARIA атрибутов для интерактивных элементов
- ⚠️ Контрастность текста не проверена

#### Решения:
- ✅ Добавить alt ко всем изображениям
- ✅ Добавить ARIA атрибуты
- ✅ Проверить контрастность

### 5. Типографика

#### Проблемы:
- ⚠️ Размеры шрифтов не всегда консистентны
- ⚠️ Межстрочные интервалы не оптимизированы

#### Решения:
- ✅ Создать типографическую шкалу
- ✅ Оптимизировать line-height
- ✅ Улучшить читабельность

## 💡 Рекомендации

### CSS Organization:
```
/public/css/
├── unified.css        # Общие стили, переменные
├── components/
│   ├── buttons.css    # Стили кнопок
│   ├── cards.css      # Стили карточек
│   ├── forms.css      # Стили форм
│   └── widgets.css    # Стили виджетов
├── pages/
│   ├── home.css       # Стили главной
│   ├── tours.css      # Стили туров
│   └── ...
└── style.css          # Главный файл (импорты)
```

### Best Practices:
1. Использовать CSS переменные для всех цветов
2. Mobile-first подход
3. Семантические HTML теги
4. Минификация для продакшена
5. Lazy loading для изображений
