## 1. ⚠️ ПОЛНАЯ ПЕРЕДЕЛКА ЛИЧНЫХ КАБИНЕТОВ (КРИТИЧНО!)

### Проблемы:
- ❌ **Не централизовано** - функции разбросаны по разным местам
- ❌ **Смена пароля** на сайте И в личном кабинете - не связаны между собой
- ❌ **Просмотр заявок** на сайте И в личном кабинете - дублирование, не связаны
- ❌ **Чат НЕ РАБОТАЕТ** - критическая проблема
- ❌ **Ненужные значки** и элементы интерфейса
- ❌ **У админа нет статистики** и управления
- ❌ Много мусора, ненужных кнопок
- ❌ Нет логики, разный макет
- ❌ Неудобный интерфейс, плохое юзабилити

### Решение: Единая централизованная система

#### 1.1. Объединение функций
- [ ] Убрать дублирование заявок (один список везде)
- [ ] Смена пароля только в настройках кабинета
- [ ] Единая навигация для всех ролей
- [ ] Все функции доступны из одного места

#### 1.2. Функциональность по ролям

**Турист:**
- [ ] Dashboard с актуальной информацией
- [ ] Мои заявки (полный список с фильтрами)
- [ ] **Чат с менеджером (ИСПРАВИТЬ - сейчас не работает!)**
- [ ] Мои документы
- [ ] Настройки профиля (включая смену пароля)

**Менеджер:**
- [ ] Dashboard с метриками
- [ ] Мои клиенты
- [ ] Мои заявки (назначенные)
- [ ] **Чат с клиентами (ИСПРАВИТЬ - сейчас не работает!)**
- [ ] Статистика работы
- [ ] Настройки

**Админ:**
- [ ] Dashboard с **полной статистикой** (сейчас нет!)
- [ ] Управление пользователями
- [ ] Управление заявками (все заявки)
- [ ] Управление ролями
- [ ] Статистика системы
- [ ] Настройки системы
- [ ] Модерация контента

#### 1.3. Технические улучшения
- [ ] **Исправить чат** (критично!)
- [ ] Убрать все ненужные элементы
- [ ] Единый стиль и макет
- [ ] Адаптивный дизайн
- [ ] Улучшенная навигация
