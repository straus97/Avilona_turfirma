### 2. Автоматическое обновление (Hot Reload)
- ✅ Обновлен `vite.config.js`
- ✅ Добавлено отслеживание views/controllers/routes
- ✅ Включен polling для стабильной работы

**Изменения в vite.config.js:**
```javascript
refresh: [
    'resources/views/**',
    'app/Http/Controllers/**',
    'routes/**',
],
server: {
    hmr: { host: 'localhost' },
    watch: { usePolling: true },
}
```

**Как работает:**
- Изменения в `.blade.php` → автообновление страницы
- Изменения в CSS/JS → hot reload без перезагрузки
- Изменения в PHP → может потребоваться Ctrl+F5
