### 5. Исправление ошибок

#### Ошибка с полями таблицы news:
**Проблема:**
```
SQLSTATE[42S22]: Column not found: 1054 Unknown column 'content'
```

**Решение:**
```php
// Было:
News::select('id', 'title', 'slug', 'content', 'image', 'created_at')

// Стало:
News::select('id', 'title', 'link', 'description', 'image', 'pub_date')
```
