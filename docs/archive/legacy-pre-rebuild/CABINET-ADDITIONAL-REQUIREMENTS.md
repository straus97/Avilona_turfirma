### 3. Система чатов (расширенная)

**Важно:**
- ❗ **История чатов сохраняется навсегда**
- ❗ **Один турист может иметь НЕСКОЛЬКО чатов с РАЗНЫМИ менеджерами**
- ❗ **При смене менеджера создается НОВЫЙ чат** (старый сохраняется)

**Логика:**
1. Турист создает заявку → система назначает менеджера → создается чат
2. Менеджер уходит на больничный → админ переназначает другого менеджера → создается новый чат
3. У туриста в списке чатов:
   - Чат с Менеджером А (заявка #123) - архивный
   - Чат с Менеджером Б (заявка #123) - активный
   - Чат с Менеджером А (заявка #456) - активный

**Структура БД:**
- `messages` таблица привязана к `booking_id` + `manager_id`
- Группировка чатов по `booking_id` + `manager_id`

**UI для туриста:**
```
Мои чаты
├── Заявка #123 "Турция, Анталья"
│   ├── Чат с Иван Иванов (01.01 - 15.01) [архив]
│   └── Чат с Петр Петров (15.01 - сейчас) [активен]
└── Заявка #456 "Египет, Хургада"
    └── Чат с Иван Иванов (20.01 - сейчас) [активен]
```

**Функционал:**
- [ ] История всех чатов (не удаляется)
- [ ] Фильтр: активные / архивные
- [ ] Индикатор активного менеджера
- [ ] Причина смены менеджера (системное сообщение в чате)
- [ ] Передача контекста новому менеджеру (доступ к истории)

**Цель:** Полная прозрачность коммуникации, никакая информация не теряется.

### 5. Бонусная программа (детальная проработка)

**Концепция:**
Накопление баллов за поездки → обмен на скидки/бонусы → мотивация возвращаться.

**Как начисляются баллы:**
- [ ] За каждый рубль заказа = 1 балл (или 1% от суммы)
- [ ] Бонус за первую поездку (500 баллов)
- [ ] Бонус за день рождения (1000 баллов)
- [ ] Бонус за отзыв с фото (300 баллов)
- [ ] Бонус за рекомендацию друга (500 баллов, если друг оформил заявку)

**Как использовать:**
- [ ] 100 баллов = 100 рублей скидки
- [ ] Можно списать до 10% от стоимости заказа
- [ ] Баллы сгорают через 1 год (настраиваемо)

**Уровни лояльности:**
- [ ] **Новичок** (0-5 000 баллов) - 1% кешбэка
- [ ] **Серебро** (5 000-20 000) - 2% кешбэка + приоритетная поддержка
- [ ] **Золото** (20 000-50 000) - 3% кешбэка + ранний доступ к акциям
- [ ] **Платина** (50 000+) - 5% кешбэка + персональный менеджер + VIP сервис

**Реферальная программа:**
- [ ] Уникальная реферальная ссылка для каждого
- [ ] Друг регистрируется по ссылке → получает 500 баллов
- [ ] Реферер получает 500 баллов когда друг оформляет заявку
- [ ] Статистика: сколько друзей пригласил

**UI в кабинете туриста:**
```
Бонусная программа
├── Баланс: 12 500 баллов (= 12 500 ₽)
├── Уровень: Серебро (до Золота 7 500 баллов)
├── История начислений/списаний
├── Каталог вознаграждений
└── Реферальная программа
    ├── Моя ссылка: https://avilona.ru/ref/ABC123
    ├── Приглашено друзей: 5
    └── Заработано: 2 500 баллов
```

**Администрирование:**
- [ ] Админ настраивает правила начисления
- [ ] Ручное начисление/списание баллов
- [ ] Статистика по программе
- [ ] Отчеты (активность, эффективность)

**Цель:** Увеличение retention (возврата клиентов) и привлечение новых через рекомендации.

## 📂 ОБНОВЛЕННАЯ СТРУКТУРА БД

### Новые таблицы:

```sql
-- Личные документы туриста
CREATE TABLE user_documents (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT UNSIGNED NOT NULL,
    document_type ENUM('passport', 'foreign_passport', 'birth_certificate', 'visa', 'other'),
    title VARCHAR(255),
    file_path VARCHAR(255),
    file_size INT,
    uploaded_at TIMESTAMP,
    version INT DEFAULT 1,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    deleted_at TIMESTAMP NULL,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

-- Документы по заявкам (от менеджера)
CREATE TABLE booking_documents (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    booking_id BIGINT UNSIGNED NOT NULL,
    document_type ENUM('contract', 'voucher', 'tickets', 'insurance', 'instructions', 'other'),
    title VARCHAR(255),
    file_path VARCHAR(255),
    file_size INT,
    uploaded_by BIGINT UNSIGNED NOT NULL, -- manager_id
    uploaded_at TIMESTAMP,
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    deleted_at TIMESTAMP NULL,
    FOREIGN KEY (booking_id) REFERENCES bookings(id) ON DELETE CASCADE,
    FOREIGN KEY (uploaded_by) REFERENCES users(id)
);

-- Бонусная программа
CREATE TABLE bonus_accounts (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT UNSIGNED NOT NULL UNIQUE,
    balance INT DEFAULT 0,
    total_earned INT DEFAULT 0,
    total_spent INT DEFAULT 0,
    level ENUM('newbie', 'silver', 'gold', 'platinum') DEFAULT 'newbie',
    referral_code VARCHAR(20) UNIQUE,
    referred_by BIGINT UNSIGNED NULL,
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (referred_by) REFERENCES users(id) ON DELETE SET NULL
);

CREATE TABLE bonus_transactions (
    id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    user_id BIGINT UNSIGNED NOT NULL,
    type ENUM('earn', 'spend', 'expire'),
    amount INT,
    reason VARCHAR(255),
    booking_id BIGINT UNSIGNED NULL,
    expires_at TIMESTAMP NULL,
    created_at TIMESTAMP,
    updated_at TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY (booking_id) REFERENCES bookings(id) ON DELETE SET NULL
);

-- История чатов (расширение messages)
-- Добавить manager_id в messages для группировки
ALTER TABLE messages ADD COLUMN manager_id BIGINT UNSIGNED NULL AFTER receiver_id;
ALTER TABLE messages ADD FOREIGN KEY (manager_id) REFERENCES users(id) ON DELETE SET NULL;
```
