# Личный кабинет туриста - Документация

**Дата создания:** 2026-01-10

## 📋 Обзор

Реализован полнофункциональный личный кабинет для туристов (пользователей с ролью `tourist`). Кабинет предоставляет возможность управления заявками, общения с менеджером, работы с документами и настройками профиля.

---

## 🎯 Основной функционал

### 1. Главная страница (Dashboard)
**Маршрут:** `/profile/dashboard`  
**Контроллер:** `ProfileController@dashboard`  
**View:** `resources/views/profile/dashboard.blade.php`

### 2. Мои заявки
**Маршрут:** `/profile/bookings`  
**Контроллер:** `ProfileController@bookings`  
**View:** `resources/views/profile/bookings.blade.php`

#### Функции:
- Полный список заявок пользователя
- Фильтрация и пагинация (10 заявок на страницу)
- Отображение информации:
  - Номер заявки
  - Название тура и направление
  - Даты поездки
  - Количество туристов
  - Статус заявки
  - Назначенный менеджер
  - Дата создания
- Быстрые действия:
  - Просмотр заявки
  - Редактирование (только для статуса "pending")
  - Переход в чат с менеджером

#### Статусы заявок:
- 🟡 **В обработке** (`pending`) - заявка принята, ожидает обработки
- 🔵 **Подтверждена** (`confirmed`) - менеджер подтвердил заявку
- 🟢 **Завершена** (`completed`) - тур завершен
- 🔴 **Отменена** (`cancelled`) - заявка отменена

**Маршрут:** `/profile/chat/{bookingId?}`

### 4. Документы
**Маршрут:** `/profile/documents`  
**Контроллер:** `ProfileController@documents`  
**View:** `resources/views/profile/documents.blade.php`

#### Функции:
- Список заявок с документами
- Просмотр всех документов по каждой заявке
- Скачивание документов
- Просмотр документов в браузере
- Загрузка новых документов (для статусов "pending" и "confirmed")
- Информация о типах документов

#### Поддерживаемые форматы:
- PDF (договоры, ваучеры)
- JPG, PNG (сканы документов)
- DOC, DOCX (дополнительные документы)
- Максимальный размер: 10 МБ

#### Типы документов:
- Договор на оказание туристических услуг
- Ваучеры и путевки
- Страховые полисы
- Билеты на транспорт
- Подтверждения бронирования отелей
- Памятки туристу

**Маршрут:** `/profile/settings`

  - Модальное окно с подтверждением
  - Ввод пароля для подтверждения
  - Необратимое действие с удалением всех данных

## 🔐 Безопасность и доступ

### Middleware:
- `auth` - только для авторизованных пользователей
- `verified` - email должен быть подтвержден
- `role:tourist,manager,admin` - доступ для указанных ролей

### Проверки доступа:
- Пользователь может видеть только свои заявки
- Пользователь может общаться только с назначенным менеджером
- Пользователь может загружать документы только к своим заявкам
- Редактирование заявки доступно только в статусе "pending"

## 📝 Маршруты

```php
Route::middleware(['auth', 'verified', 'role:tourist,manager,admin'])
    ->prefix('profile')
    ->name('profile.')
    ->group(function () {
        Route::get('/dashboard', [ProfileController::class, 'dashboard'])
            ->name('dashboard');
        
        Route::get('/bookings', [ProfileController::class, 'bookings'])
            ->name('bookings');
        
        Route::get('/chat/{bookingId?}', [ProfileController::class, 'chat'])
            ->name('chat');
        
        Route::get('/documents', [ProfileController::class, 'documents'])
            ->name('documents');
        
        Route::post('/documents/{booking}/upload', [ProfileController::class, 'uploadDocument'])
            ->name('upload-document');
        
        Route::get('/settings', [ProfileController::class, 'edit'])
            ->name('edit');
        
        Route::patch('/settings', [ProfileController::class, 'update'])
            ->name('update');
        
        Route::delete('/settings', [ProfileController::class, 'destroy'])
            ->name('destroy');
    });
```
