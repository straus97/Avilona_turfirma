## 🛠 Инструменты для тестирования

### Автоматическое тестирование
- PHPUnit для unit тестов
- Laravel Dusk для browser тестов
- Pest (опционально) для более удобного синтаксиса

### Ручное тестирование
- Проверка в разных браузерах (Chrome, Firefox, Edge)
- Проверка на разных устройствах (десктоп, планшет, мобильный)
- Проверка с разными разрешениями экрана

### Инструменты анализа
- Laravel Debugbar для анализа запросов
- Lighthouse для проверки производительности
- W3C Validator для проверки HTML
