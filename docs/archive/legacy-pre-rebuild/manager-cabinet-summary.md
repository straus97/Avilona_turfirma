# Кабинет менеджера - Документация

**Дата создания:** 2026-01-10  
**Статус:** ✅ Завершено

---

## 📋 Обзор

Реализован полнофункциональный кабинет для менеджеров (пользователей с ролью `manager` или `admin`). Кабинет предоставляет инструменты для управления заявками клиентов, общения с ними, просмотра статистики работы.

---

## 🎯 Основной функционал

### 1. Главная страница (Dashboard)
**Маршрут:** `/manager/dashboard`  
**Контроллер:** `ManagerController@dashboard`  
**View:** `resources/views/manager/dashboard.blade.php`

#### Функции:
- **Статистические карточки:**
  - Всего назначенных заявок
  - Новые заявки (требуют обработки)
  - Подтвержденные заявки (в работе)
  - Непрочитанные сообщения
  - Количество клиентов
  - Завершенные заявки
  - Общий доход (завершенные заявки)
- Список последних 10 заявок
- Быстрые действия
- Информационная панель

---

### 2. Список клиентов
**Маршрут:** `/manager/clients`  
**Контроллер:** `ManagerController@clients`  
**View:** `resources/views/manager/clients.blade.php`

#### Функции:
- Полный список клиентов менеджера (с пагинацией)
- Отображение информации:
  - Имя и email клиента
  - Телефон (с возможностью звонка)
  - Количество заявок
  - Количество активных заявок
  - Последняя заявка
- Быстрые действия:
  - Просмотр всех заявок клиента
  - Переход в чат с клиентом
- Советы по работе с клиентами

---

### 3. Управление заявками
**Маршрут:** `/manager/bookings`  
**Контроллер:** `ManagerController@bookings`  
**View:** `resources/views/manager/bookings.blade.php`

#### Функции:
- **Фильтрация по статусам:**
  - Все заявки
  - В обработке
  - Подтверждены
  - Завершены
  - Отменены
- **Поиск:**
  - По названию тура
  - По направлению
  - По имени/email клиента
- **Таблица заявок с информацией:**
  - Номер заявки
  - Клиент (имя + email)
  - Тур и направление
  - Даты поездки
  - Количество туристов
  - Цена
  - Статус
  - Дата создания
- **Действия:**
  - Просмотр заявки
  - Чат с клиентом
  - Подтверждение (для статуса "pending")
  - Завершение (для статуса "confirmed")
- Пагинация (15 заявок на страницу)
- Счетчики по статусам

### 4. Чат с клиентами
**Маршрут:** `/manager/chat/{bookingId?}`  
**Контроллер:** `ManagerController@chat`

#### Функции:
- Список всех заявок менеджера
- Индикаторы непрочитанных сообщений
- Окно чата с историей переписки
- Информация о заявке над чатом
- Отправка текстовых сообщений
- Прикрепление файлов
- Автоматическая прокрутка к последнему сообщению
- Автообновление чата каждые 30 секунд
- Автоматическая отметка сообщений как прочитанных
- **Быстрые действия:**
  - Подтвердить заявку (для статуса "pending")
  - Завершить заявку (для статуса "confirmed")
  - Просмотреть заявку

## 🔐 Безопасность и доступ

### Middleware:
- `auth` - только для авторизованных пользователей
- `role:manager,admin` - доступ только для менеджеров и администраторов

### Проверки доступа:
- Менеджер видит только назначенные ему заявки
- Менеджер может общаться только с клиентами по своим заявкам
- Менеджер видит статистику только по своим заявкам
- Действия по подтверждению/завершению заявок доступны только для своих заявок

## 📝 Маршруты

```php
Route::middleware(['auth', 'role:manager,admin'])
    ->prefix('manager')
    ->name('manager.')
    ->group(function () {
        Route::get('/dashboard', [ManagerController::class, 'dashboard'])
            ->name('dashboard');
        
        Route::get('/clients', [ManagerController::class, 'clients'])
            ->name('clients');
        
        Route::get('/bookings', [ManagerController::class, 'bookings'])
            ->name('bookings');
        
        Route::get('/chat/{bookingId?}', [ManagerController::class, 'chat'])
            ->name('chat');
        
        Route::get('/statistics', [ManagerController::class, 'statistics'])
            ->name('statistics');
    });
```

## 🎯 Особенности реализации

### 1. Динамическое меню
Меню в sidebar автоматически меняется в зависимости от роли:
- **Менеджер** видит: Dashboard, Заявки, Клиенты, Чат, Статистика
- **Менеджер с ролью туриста** дополнительно видит: переключатель на личный кабинет
- **Админ** видит: все меню менеджера + админ панель

### 2. Счетчики в реальном времени
- Непрочитанные сообщения отображаются в меню

- Сохранение параметров поиска в URL
- Пагинация с сохранением фильтров
- Быстрая фильтрация по статусам
