# 📧 ПОШАГОВАЯ ИНСТРУКЦИЯ: Настройка Email-уведомлений

## ⚠️ ВАЖНО: Читайте все шаги последовательно!

---

## ШАГ 1: Определяемся с выбором SMTP сервиса

У вас есть 3 варианта:

### Вариант А: Mailtrap (ДЛЯ ТЕСТИРОВАНИЯ) ⭐ РЕКОМЕНДУЮ ДЛЯ НАЧАЛА
**Плюсы:**
- ✅ Бесплатно
- ✅ Не отправляет реальные письма (все идет в тестовый inbox)
- ✅ Идеально для разработки
- ✅ Не нужно настраивать Gmail

**Минусы:**
- ❌ Письма не доходят до реальных пользователей (только для тестов)

### Вариант Б: Gmail (ДЛЯ РЕАЛЬНОЙ РАБОТЫ)
**Плюсы:**
- ✅ Бесплатно
- ✅ Реальные письма доходят до пользователей
- ✅ Надежный сервис

**Минусы:**
- ❌ Нужно настроить пароль приложения
- ❌ Могут попадать в спам

### Вариант В: SendGrid/Mailgun (ДЛЯ ПРОДАКШЕНА)
**Плюсы:**
- ✅ Профессиональный сервис
- ✅ Не попадает в спам
- ✅ Хорошая доставляемость

**Минусы:**
- ❌ Платно (но есть бесплатный лимит)

## ШАГ 2: Выбираем вариант и настраиваем

### 📌 ВАРИАНТ А: Mailtrap (для тестирования)

#### 2.1. Регистрация в Mailtrap

1. Откройте https://mailtrap.io/
2. Нажмите "Sign Up" (регистрация бесплатная)
3. Заполните форму
4. Войдите в аккаунт

#### 2.2. Создание Inbox

1. В личном кабинете нажмите "Add Inbox" или "Create Inbox"
2. Выберите название (например: "Avilona Development")
3. Нажмите "Create Inbox"

#### 2.3. Получение SMTP настроек

1. Кликните на созданный inbox
2. Перейдите во вкладку "SMTP Settings"
3. Выберите "Laravel" в списке интеграций
4. Скопируйте следующие данные:
   - **Host:** `smtp.mailtrap.io`
   - **Port:** `2525`
   - **Username:** (ваш username, например: `a1b2c3d4e5f6g7`)
   - **Password:** (ваш password, например: `h8i9j0k1l2m3n4`)

---

### 📌 ВАРИАНТ Б: Gmail (для реальной работы)

#### 2.1. Включение двухфакторной аутентификации

1. Откройте https://myaccount.google.com/
2. Войдите в свой Gmail аккаунт
3. Перейдите в раздел "Безопасность" (Security)
4. Найдите "Двухэтапная аутентификация" (2-Step Verification)
5. Нажмите "Начать" и следуйте инструкциям
6. Включите двухфакторную аутентификацию

#### 2.2. Создание пароля приложения

1. Откройте https://myaccount.google.com/apppasswords
   - (Если ссылка не работает, вручную: Google Account → Security → 2-Step Verification → App passwords)
2. В разделе "Выберите приложение" выберите "Почта"
3. В разделе "Выберите устройство" выберите "Другое (Введите название)"
4. Введите название: `Avilona Website`
5. Нажмите "Создать"
6. **ВАЖНО:** Скопируйте 16-значный пароль, который покажется (формат: `xxxx xxxx xxxx xxxx`)
   - ⚠️ Этот пароль показывается только один раз!
   - ⚠️ Сохраните его в безопасном месте

#### 2.3. SMTP настройки для Gmail

Используйте следующие настройки:
- **Host:** `smtp.gmail.com`
- **Port:** `587`
- **Username:** ваш Gmail адрес (например: `your-email@gmail.com`)
- **Password:** пароль приложения из шага 2.2 (16 символов БЕЗ пробелов: `xxxxxxxxxxxxxxxx`)
- **Encryption:** `tls`

## ШАГ 3: Добавление настроек в .env файл

### 3.1. Откройте файл .env

Файл находится в корне проекта: `C:\wamp\www\Avilona_turfirma\.env`

**Если файла .env нет:**
1. Скопируйте `.env.example` в `.env`
2. Или создайте новый файл `.env`

### 3.2. Найдите или добавьте секцию с настройками почты

Добавьте в конец файла `.env` следующее:

#### Для Mailtrap (вариант А):
```env
# ============================================
# EMAIL НАСТРОЙКИ (MAILTRAP - ДЛЯ ТЕСТИРОВАНИЯ)
# ============================================
MAIL_MAILER=smtp
MAIL_HOST=smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=ваш_username_из_mailtrap
MAIL_PASSWORD=ваш_password_из_mailtrap
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=info@avilona.ru
MAIL_FROM_NAME="Авилона"
```

#### Для Gmail (вариант Б):
```env
# ============================================
# EMAIL НАСТРОЙКИ (GMAIL - ДЛЯ РЕАЛЬНОЙ РАБОТЫ)
# ============================================
MAIL_MAILER=smtp
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=ваш_email@gmail.com
MAIL_PASSWORD=xxxxxxxxxxxxxxxx
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=info@avilona.ru
MAIL_FROM_NAME="Авилона"
```

**⚠️ ВАЖНО:**
- Замените `ваш_username_из_mailtrap` на реальный username из Mailtrap
- Замените `ваш_password_из_mailtrap` на реальный password из Mailtrap
- Замените `ваш_email@gmail.com` на ваш Gmail адрес
- Замените `xxxxxxxxxxxxxxxx` на 16-значный пароль приложения (БЕЗ пробелов!)

### 3.3. Настройка очередей

В том же файле `.env` найдите строку:
```env
QUEUE_CONNECTION=sync
```

И замените на:
```env
QUEUE_CONNECTION=database
```

Если этой строки нет - добавьте её.

**Итоговая секция в .env должна выглядеть так:**

```env
# Email настройки
MAIL_MAILER=smtp
MAIL_HOST=smtp.mailtrap.io  # или smtp.gmail.com
MAIL_PORT=2525              # или 587 для Gmail
MAIL_USERNAME=ваш_username
MAIL_PASSWORD=ваш_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=info@avilona.ru
MAIL_FROM_NAME="Авилона"

# Очереди (для асинхронной отправки писем)
QUEUE_CONNECTION=database
```

## ШАГ 4: Создание таблиц для очередей

### 4.1. Запустите миграции

Откройте терминал в корне проекта и выполните:

```bash
php artisan migrate
```

**Что это делает:**
- Создает таблицу `jobs` (для хранения задач на отправку писем)
- Создает таблицу `failed_jobs` (для хранения неудачных попыток)

**Если вы увидите ошибку:**
- Проверьте, что база данных настроена в `.env`
- Проверьте подключение к MySQL

### 4.2. Проверьте что таблицы созданы

Откройте phpMyAdmin и убедитесь, что в базе данных появились таблицы:
- `jobs`
- `failed_jobs`

## ШАГ 5: Очистка кэша конфигурации

Выполните в терминале:

```bash
php artisan config:clear
php artisan cache:clear
```

**Зачем это нужно:**
- Laravel кэширует настройки из `.env`
- После изменения `.env` нужно очистить кэш

## ШАГ 6: Запуск воркера очередей

### 6.1. Зачем нужен воркер?

Воркер очередей обрабатывает задачи отправки писем в фоне. Без него письма **НЕ БУДУТ** отправляться!

### 6.2. Запуск воркера

Откройте **НОВЫЙ** терминал (не закрывайте текущий!) и выполните:

```bash
cd C:\wamp\www\Avilona_turfirma
php artisan queue:work
```

**Что вы должны увидеть:**
```
[2026-01-10 12:00:00] Processing: App\Mail\BookingCreated
[2026-01-10 12:00:01] Processed:  App\Mail\BookingCreated
```

**⚠️ ВАЖНО:**
- Оставьте этот терминал открытым!
- Воркер должен работать постоянно
- Если закрыть терминал - письма перестанут отправляться

**Для Windows (фоновый режим):**
Создайте файл `start-queue-worker.bat`:
```batch
@echo off
cd /d C:\wamp\www\Avilona_turfirma
php artisan queue:work
pause
```

Запускайте его двойным кликом, но не закрывайте окно.

## ШАГ 7: Тестирование отправки писем

### 7.1. Тест всех типов уведомлений

Выполните команду (замените email на свой):

```bash
php artisan test:email-notifications ваш-email@example.com
```

**Для Mailtrap:**
- Можете указать любой email (письма все равно не отправятся реально)
- Откройте inbox в Mailtrap и увидите все письма

**Для Gmail:**
- Укажите реальный Gmail адрес
- Проверьте почтовый ящик (и папку "Спам"!)

### 7.2. Что должно произойти

1. Команда найдет первую заявку в базе
2. Отправит 5 тестовых писем:
   - ✅ Создание заявки
   - ✅ Изменение статуса
   - ✅ Назначение менеджера (если есть)
   - ✅ Напоминание о поездке
   - ✅ Новое сообщение (если есть)

3. В терминале воркера вы увидите:
   ```
   Processing: App\Mail\BookingCreated
   Processed:  App\Mail\BookingCreated
   ```

### 7.3. Проверка результата

**Для Mailtrap:**
1. Откройте https://mailtrap.io/
2. Войдите в аккаунт
3. Откройте ваш inbox
4. Увидите все отправленные письма
5. Можете проверить их содержимое, HTML, и т.д.

**Для Gmail:**
1. Откройте почтовый ящик
2. Проверьте входящие письма
3. Если не видите - проверьте папку "Спам"
4. Откройте письмо и проверьте форматирование

## ШАГ 8: Тестирование реальной отправки

### 8.1. Создайте тестовую заявку

1. Откройте сайт в браузере
2. Зарегистрируйтесь или войдите в аккаунт
3. Перейдите на `/bookings/create`
4. Заполните форму и создайте заявку
5. Нажмите "Создать заявку"

### 8.2. Что должно произойти

1. Заявка создается в базе
2. Автоматически отправляется email клиенту
3. В терминале воркера появится:
   ```
   Processing: App\Mail\BookingCreated
   ```

4. Проверьте почту (Mailtrap inbox или Gmail)

### 8.3. Проверка других уведомлений

**Тест изменения статуса:**
1. Войдите как менеджер или админ
2. Откройте заявку
3. Измените статус на "Подтверждена"
4. Должно прийти письмо об изменении статуса

**Тест нового сообщения:**
1. Откройте чат с заявкой
2. Напишите сообщение
3. Должно прийти письмо получателю

## ШАГ 9: Настройка автоматических напоминаний (опционально)

### 9.1. Что это?

Система автоматически отправляет напоминания о поездке за:
- 14 дней до вылета
- 7 дней до вылета
- 3 дня до вылета
- 1 день до вылета

### 9.2. Ручной запуск (для теста)

```bash
php artisan bookings:send-trip-reminders
```

**Что произойдет:**
- Система найдет все подтвержденные заявки
- Проверит дату вылета
- Отправит напоминания если до вылета 1, 3, 7 или 14 дней

### 9.3. Автоматический запуск (для продакшена)

**Для Windows (через Task Scheduler):**

1. Откройте "Планировщик заданий" (Task Scheduler)
2. Создайте новое задание
3. Триггер: ежедневно в 10:00
4. Действие: запустить программу
   - Программа: `C:\wamp\bin\php\php8.x\php.exe`
   - Аргументы: `artisan schedule:run`
   - Рабочая папка: `C:\wamp\www\Avilona_turfirma`

**Для Linux (через cron):**
```bash
crontab -e
# Добавьте строку:
* * * * * cd /var/www/avilona && php artisan schedule:run >> /dev/null 2>&1
```

## 🐛 РЕШЕНИЕ ПРОБЛЕМ

### Проблема 1: "Connection could not be established"

**Решение:**
- Проверьте `MAIL_HOST` и `MAIL_PORT` в `.env`
- Проверьте интернет-соединение
- Для Gmail убедитесь, что используете пароль приложения, а не обычный пароль

### Проблема 2: "Authentication failed"

**Решение:**
- Проверьте `MAIL_USERNAME` и `MAIL_PASSWORD`
- Для Gmail убедитесь, что пароль приложения правильный (16 символов БЕЗ пробелов)
- Для Mailtrap проверьте что скопировали правильные credentials

### Проблема 3: Письма не отправляются

**Решение:**
1. Проверьте что воркер очередей запущен: `php artisan queue:work`
2. Проверьте таблицу `jobs` в БД - есть ли там задачи?
3. Проверьте `failed_jobs` - есть ли ошибки?
4. Проверьте логи: `storage/logs/laravel.log`

### Проблема 4: Письма попадают в спам (Gmail)

**Решение:**
- Добавьте email отправителя в контакты
- Настройте SPF и DKIM для домена (для продакшена)
- Используйте корпоративную почту вместо Gmail

### Проблема 5: "Class 'App\Mail\BookingCreated' not found"

**Решение:**
```bash
composer dump-autoload
php artisan config:clear
php artisan cache:clear
```
